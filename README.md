# یادآور صوتی — پروژه اولیه اندروید

اپ فارسی React + Vite + Capacitor برای ثبت کار، تبدیل گفتار فارسی به متن و یادآوری محلی.

## پیش‌نیازها
- Node.js نسخه LTS (ترجیحاً 20 یا 22)
- برای تولید APK محلی: Android SDK و JDK سازگار با نسخه Android Gradle Plugin نصب‌شده توسط Capacitor
- گوشی اندرویدی با سرویس تشخیص گفتار که زبان فارسی (`fa-IR`) را پشتیبانی کند

## نصب و اجرای وب
```bash
npm install
npm run dev
```
پیش‌نمایش وب برای بررسی ظاهر و فرم‌هاست؛ میکروفون بومی و یادآوری قابل‌اعتماد در پس‌زمینه فقط با اجرای نسخه اندروید قابل ارزیابی است.

## ساخت پروژه Android
در ترمینال داخل پوشه پروژه:
```bash
npm install
npm run build
npm run android:add
npm run cap:sync
```
اگر دستور `npm run android:add` گفت پلتفرم از قبل اضافه شده، آن را دوباره اجرا نکن. سپس:
```bash
npm run cap:open
```
پوشه Android را در Android Studio باز کن و از منوی Build، گزینه ساخت APK را انتخاب کن. Android Studio فقط برای ساخت نهایی محلی لازم است؛ اگر نصب SDK آن مشکل دارد، می‌توان از محیط CI مانند GitHub Actions با Android SDK استفاده کرد.

## نکات مهم و محدودیت‌ها
- این پروژه APK از پیش ساخته‌شده نیست؛ سورس آماده است و برای APK باید وابستگی‌ها نصب و پروژه اندروید sync/build شود.
- تشخیص گفتار با سرویس گفتار سیستم‌عامل انجام می‌شود؛ پشتیبانی فارسی و نیاز به اینترنت به گوشی و سرویس نصب‌شده بستگی دارد.
- اعلان محلی با Capacitor Local Notifications زمان‌بندی می‌شود. برای رفتار دقیق در حالت Doze، پس از راه‌اندازی روی گوشی، مجوز اعلان و در صورت نیاز مجوز/تنظیمات هشدار دقیق را بررسی کن. سازنده گوشی ممکن است با بهینه‌سازی باتری اجرای دقیق را محدود کند.
- برای استفاده از اعلان‌ها، پس از نصب APK مجوز اعلان را بده. در تنظیمات Android، باتری برنامه را روی حالت محدودنشده قرار بده اگر اعلان‌ها دیر می‌رسند.
- زمان‌های گفتاری فعلاً با قواعد ساده پردازش می‌شوند (مانند «یک ساعت دیگه»، «۲۰ دقیقه دیگه»، «فردا ساعت ۹»). عبارت‌های مبهم را در فرم اصلاح کن.
- یادداشت‌ها با Capacitor Preferences روی دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های برنامه می‌تواند آن‌ها را حذف کند.
- فونت آنلاین Vazirmatn در صورت دسترسی شبکه بارگذاری می‌شود؛ در حالت آفلاین فونت جایگزین سیستم استفاده خواهد شد.

## مجوزهای مورد انتظار
پلاگین‌ها مجوزهای لازم خود را به manifest اضافه می‌کنند. اگر مجوز میکروفون/تشخیص گفتار در خروجی نهایی دیده نشد، Manifest ادغام‌شده را در پروژه Android بررسی کن و فقط مجوزهای مستندشده برای نسخه پلاگین را اضافه کن.

## تست پذیرش روی گوشی واقعی
1. APK نصب شود و اولین بار مجوز اعلان و گفتار درخواست شود.
2. روی میکروفون بزن و فارسی بگو: «۲۰ دقیقه دیگه آب بخور».
3. متن و زمان تشخیص‌داده‌شده را بررسی و ذخیره کن.
4. برنامه را ببند و منتظر اعلان بمان.
5. گوشی را ری‌استارت کن و رفتار یادآور را جداگانه تست کن؛ بازیابی اعلان پس از راه‌اندازی مجدد باید با نسخه دقیق پلاگین و اندروید تأیید شود.
6. تست کن حذف/تکمیل کار، اعلان مربوط به آن را لغو کند.

## ساختار
- `src/App.tsx`: رابط، ذخیره کارها، تحلیل ساده عبارت زمانی و اعلان‌ها
- `src/styles.css`: طراحی تیره و واکنش‌گرا
- `capacitor.config.ts`: شناسه اپ و تنظیمات Capacitor
